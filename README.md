# Aya AI — مشروع بداية قابل للتشغيل

واجهة عربية داكنة لتوليد الصور والفيديو، مع خادم Express وسجل SQLite.

## المتطلبات
- Node.js 20 أو أحدث
- حساب Replicate ومفتاح API صالح

## التشغيل المحلي
1. فك ضغط المشروع.
2. افتحي الطرفية داخل مجلد المشروع وشغّلي:
   ```bash
   npm install
   ```
3. انسخي `.env.example` إلى `.env`.
4. ضعي مفتاح Replicate في `REPLICATE_API_TOKEN`.
5. شغّلي:
   ```bash
   npm run dev
   ```
6. افتحي `http://localhost:5173`.

## النشر
- اضبطي أمر البناء `npm run build`.
- أمر التشغيل `npm start`.
- أضيفي متغيرات البيئة في منصة الاستضافة.
- استخدمي خدمة تخزين دائمة لملف `server/data/aya-ai.sqlite` عند النشر؛ أنظمة الملفات المؤقتة قد تمسح قاعدة البيانات عند إعادة التشغيل.

## ملاحظات التكامل
- المفتاح لا يوضع في الواجهة الأمامية؛ يُقرأ على الخادم فقط.
- أسماء النماذج الافتراضية موجودة في `.env.example` ويمكن تغييرها.
- مدخلات النماذج تختلف من نموذج لآخر. قد تحتاج حقول `aspect_ratio` أو `duration` إلى تعديل لتطابق مخطط الإدخال للنموذج الذي تختارينه في Replicate.
- الكود يحفظ سجل الطلبات وروابط النتائج التي يرجعها Replicate. روابط المخرجات لدى Replicate قد تكون مؤقتة؛ للإنتاج الفعلي ينبغي نسخ الملفات إلى تخزين دائم عبر webhook أو مهمة خلفية.
- هذا مشروع بداية متكامل البنية، وليس خدمة مستضافة أو حساب API مدفوعاً جاهزاً.
